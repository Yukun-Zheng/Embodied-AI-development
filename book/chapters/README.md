# 两种正文层级

```text
book/volumes/      → 卷级连续通读版，强调知识主线
book/chapters/     → Part 0–50 独立深章，强调机制、公式、实验与研究问题
```

两层并存不是重复：Volume 负责“先看懂整片森林”，Chapter 负责“进入每棵树的机制”。后续出版级扩展以 `book/chapters/` 为主稿源。
