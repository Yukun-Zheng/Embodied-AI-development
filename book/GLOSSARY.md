# Glossary　具身智能中英术语表

> 本表规定本书的优先译法。第一次出现可写“中文（English, abbreviation）”；后续优先保持一致。某些术语中文尚无唯一共识，因此同时保留英文。

## A

- **Action** — 动作；策略输出并最终影响环境的控制变量。
- **Action Chunk** — 动作块；连续多个未来时间步的动作序列。
- **Action Space** — 动作空间。
- **Actuator** — 执行器。
- **Active Perception** — 主动感知。
- **Active Vision** — 主动视觉。
- **Admittance Control** — 导纳控制。
- **Affordance** — 可供性 / 行动可供性；对象相对于某 embodiment 提供的行动可能性。
- **Agent** — 智能体。
- **Aleatoric Uncertainty** — 偶然不确定性 / 数据不确定性。
- **Autonomy** — 自主性。

## B

- **Backdrivability** — 可反驱性。
- **Behavior Cloning (BC)** — 行为克隆。
- **Belief State** — 信念状态；对隐藏世界状态的概率分布。
- **Bimanual Manipulation** — 双臂操作。
- **Body Frame** — 机体坐标系 / 本体坐标系；正文视上下文避免与 embodiment 的“本体”混淆。

## C

- **Calibration** — 标定。
- **Catastrophic Forgetting** — 灾难性遗忘。
- **Centralized Training, Decentralized Execution (CTDE)** — 集中训练、分散执行。
- **Closed-Loop Control** — 闭环控制。
- **Collision Checking** — 碰撞检测。
- **Compositional Generalization** — 组合泛化。
- **Compliance** — 柔顺性。
- **Configuration** — 构型 / 位形。
- **Configuration Space (C-space)** — 构型空间。
- **Contact-Rich Manipulation** — 富接触操作 / 接触密集操作。
- **Control Barrier Function (CBF)** — 控制障碍函数。
- **Covariate Shift** — 协变量偏移。
- **Cross-Embodiment** — 跨本体 / 跨身体；本书通常写“跨本体（cross-embodiment）”。

## D

- **DAgger** — Dataset Aggregation，数据集聚合模仿学习算法。
- **Demonstration** — 示范轨迹 / 演示数据。
- **Dexterous Manipulation** — 灵巧操作。
- **Diffusion Policy** — 扩散策略。
- **Digital Twin** — 数字孪生。
- **Domain Randomization** — 域随机化。
- **Dynamics** — 动力学。

## E

- **Embodied AI** — 具身人工智能 / 具身智能；本书标题采用“具身智能”。
- **Embodied Reasoning** — 具身推理。
- **Embodiment** — 本体 / 身体形态及其传感—执行—动力学约束。不要仅译为“机器人类型”。
- **End Effector (EE)** — 末端执行器。
- **Epistemic Uncertainty** — 认知不确定性 / 模型不确定性。
- **Episode** — 回合 / 完整交互片段。
- **Equivariance** — 等变性。
- **Extrinsics** — 外参。

## F

- **Feedback Control** — 反馈控制。
- **Flow Matching** — 流匹配。
- **Force Closure** — 力闭合。
- **Force/Torque Sensor (F/T)** — 力/力矩传感器。
- **Forward Dynamics** — 正向动力学。
- **Forward Kinematics (FK)** — 正运动学。

# 容易混淆的术语

### State vs Observation

**State** 应足以预测未来（在模型假设下满足 Markov）；**observation** 是传感器当前能测到的量。RGB frame 通常只是 observation。

### Embodiment vs Morphology

**Morphology** 偏身体结构/形态；**embodiment** 更广，还包含传感器、执行器、动作接口和动力学能力。

### Planning vs Reasoning

**Planning** 通常明确搜索未来 action/state sequence；**reasoning** 更宽，可能包括语义解释、工具调用、任务分解。论文若只输出文字步骤，应避免直接宣称获得 motor planning 能力。

### World Model vs Video Generator

能生成未来视频的模型可视为 observation-space predictive model，但只有在 action-conditioned future、counterfactual、physical executability 和 downstream control 上成立，才更有资格被当作机器人 world model。

### Generalist vs General

**Generalist** 常指同一模型覆盖许多训练任务；**general intelligence** 需要更强的未见组合、跨环境、跨本体和持续学习能力。不要混用。

### Safety vs Reliability

**Safety** 关心 hazard 与损害；**reliability** 关心系统是否持续按预期完成任务。一个系统可以可靠地执行一个不安全策略，也可以安全停机却任务成功率低。

# 写作约定

- VLA、VLM、RL、MPC、SLAM 等国际通用缩写直接保留；
- 首次出现不常见英文缩写必须展开；
- “本体”在 `embodiment` 与 `proprioception` 两个语义中容易歧义，正文优先通过上下文或保留英文消歧；
- `world model` 在模型类别名称中优先保留英文并给中文解释；
- 不为了中文化而牺牲机器人学国际文献可检索性。
