# 维护原则

1. 每个 Part 至少有一个 foundation/primary source；
2. 前沿章节必须记录 dated official source，不用品牌宣传替代机制证据；
3. 若 source claim 发生版本变化，在 Chapter / Timeline / Model Atlas 同步校正；
4. 源码型 claim 优先指向官方 repository + canonical Case Study；
5. source map 是入口，不替代正文中的局部 evidence attribution。真正重要的数字、版本、能力 claim 仍应在正文就地给 source anchor。
